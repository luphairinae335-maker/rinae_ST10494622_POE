Instructions 
This website project contains 5 files: 
• index.html – Home page 
• about.html – About page 
• services.html – Services page 
• contact.html – Contact page 
• style.css – CSS file used to style the website 
How to Run the Website 
1. Download the complete website folder to your computer. 
2. Make sure all the files remain in the same folder. 
3. You can open the files using a text editor such as Notepad, Notepad++, or Visual Studio 
Code if you want to view or edit the source code. 
4. To open the website, locate the index.html file. 
5. Double-click index.html, or right-click it and select Open with your preferred web browser. 
6. The home page will open, and you can navigate to the About, Services, and Contact pages 
using the website navigation menu. 
Responsive Design 
The website uses a responsive layout and can be viewed on different screen sizes, including: 
• Desktop computers 
• Laptops 
• Tablets 
• Mobile phones 
The layout automatically adjusts according to the size of the user's screen. 
Important
